**Pour lire : ouvrir [index.html](index.html)** dans un navigateur. Chaque page garde le design original du cours (dégradé vert/bleu nuit, encadrés exercices/astuces/avertissements, quiz avec corrections révélées) mais en page qui défile plutôt qu'en diaporama diapo par diapo — avec une petite barre de navigation en haut (retour à l'index, séance précédente/suivante, lien vers la page source).

Un `.md` en texte brut existe aussi à côté de chaque `.html`, pratique pour une recherche rapide (`grep`) mais sans la mise en forme.
