Lexique FALC — Vibe-Coding : IA et développement web

Guide de vocabulaire rédigé en français facile à lire et à comprendre pour les adultes qui découvrent la programmation et l'intelligence artificielle.

← Sommaire de la formation Séance 1 Annexes outils

Principes de rédaction de ce lexique

Ce lexique est spécialement conçu pour les débutants. Chaque explication respecte des règles d'accessibilité strictes :

  • Longueur maîtrisée : chaque définition compte entre 10 et 25 mots.
  • Langage direct : nous employons le présent et des verbes d'action concrets (« Vous pouvez… », « Cet outil sert à… »).
  • Une seule idée par phrase : aucun jargon n'est utilisé pour expliquer un autre terme technique.
  • Distinction vie courante : lorsqu'un mot a un autre sens dans la vie de tous les jours (comme branche, jeton ou terminal), son rôle informatique est clarifié.

1. Intelligence Artificielle (IA)

Terme Explication en français facile (10 à 25 mots) Exemple simple Support visuel
Vibe-coding Vous guidez une intelligence artificielle avec vos phrases ordinaires pour fabriquer une application sans taper tout le code vous-même. Vous demandez à l'assistant d'ajouter un bouton bleu qui ouvre un formulaire de contact sur votre site. Capture d'écran Dialogue avec l'outil
Prompt
(Consigne pour l'IA)		 Cet outil reçoit votre consigne écrite rédigée en français pour savoir exactement quelle partie de l'application il doit fabriquer. Vous écrivez : « Crée une page d'accueil avec une photo et trois boutons pour mon association ». Texte encadré Modèle à copier
Assistant IA Ce programme informatique dialoguant comprend vos demandes en français et vous propose immédiatement du texte, des images ou du code. Vous posez une question à Claude ou ChatGPT pour corriger une erreur sur votre page web. Capture Fenêtre de discussion
Modèle de langage
(LLM)		 Ce moteur de calcul lit des millions de textes pour deviner la suite de mots la plus logique à votre question. Le moteur comprend votre demande et propose la suite d'une recette ou le code d'un site. Schéma Question → réponse mot par mot
Contexte
(Mémoire de l'IA)		 Cet espace de mémoire temporaire contient les règles de votre projet et l'historique de vos échanges récents avec l'assistant. Vous fournissez la liste de vos pages à l'outil pour qu'il ne crée pas de doublons. Illustration Boîte mémoire de travail
Hallucination L'outil produit une fausse information avec une totale assurance quand il ignore la véritable réponse à votre demande. L'assistant vous conseille une commande d'ordinateur qui n'existe pas et bloque votre travail. Icône alerte Panneau danger
Rôle
(pour l'IA)		 Vous demandez à l'outil d'adopter le métier d'un spécialiste pour obtenir des conseils plus précis et mieux adaptés. Vous commencez votre phrase par : « Agis comme un professeur patient pour m'expliquer cette erreur ». Illustration Badges de métiers

2. Cadrage et gestion de projet

Terme Explication en français facile (10 à 25 mots) Exemple simple Support visuel
Cadrage Vous clarifiez l'objectif de votre application, les personnes visées et les besoins prioritaires avant d'écrire la moindre ligne. Vous rédigez une page pour décrire le but exact de votre futur site d'entraide entre voisins. Fiche Modèle de cadrage
MVP
(Produit minimum utile)		 Cette toute première version fonctionnelle de votre application propose uniquement les fonctions vitales pour vérifier rapidement l'intérêt du public. Votre boutique en ligne permet seulement d'afficher un produit et de payer, sans options compliquées. Dessin Skateboard vs voiture
Persona Vous inventez un profil d'utilisateur imaginaire très détaillé pour concevoir votre application en pensant à ses besoins réels. Vous imaginez « Paul, 65 ans, jardinier bénévole », qui utilise son téléphone pour lire les nouvelles du club. Portrait Fiche d'identité illustrée
Backlog
(Liste des tâches)		 Ce registre ordonné rassemble toutes les actions à réaliser pour fabriquer votre application au fil des jours. Vous notez vingt tâches à faire, puis vous cochez celles terminées pendant la semaine. Tableau À faire / En cours / Fait
User story
(Histoire utilisateur)		 Vous formulez une phrase courte pour exprimer ce qu'un utilisateur veut accomplir sur votre site et pourquoi. Vous écrivez : « En tant que visiteur, je veux voir les horaires pour ne pas me déplacer pour rien ». Fiche Modèle de phrase colorée
Priorisation MoSCoW Cette méthode classe vos idées en trois groupes : ce qui est obligatoire, ce qui est important et ce qui peut attendre. Le panier d'achat est obligatoire immédiatement, mais le choix de couleur sombre attendra le mois prochain. Colonnes 3 couleurs d'urgence
Critères d'acceptation Cette liste de conditions obligatoires permet de certifier qu'une tâche est entièrement terminée et fonctionne sans erreur. L'inscription est validée si le mot de passe compte huit lettres et si un message vert apparaît. Checklist Cases à cocher vertes
Livrable Vous transmettez ce travail concret à votre formateur pour prouver la progression réelle de votre projet d'application. Vous remettez le plan de votre site sous la forme d'un fichier texte lisible par tous. Icône Dossier avec tampon vert

3. Web et code

Terme Explication en français facile (10 à 25 mots) Exemple simple Support visuel
Front-end
(Partie visible)		 Cet espace regroupe tout ce qui apparaît sur l'écran : textes, images, couleurs, menus et boutons d'action. La barre de recherche et les photos de votre site composent la partie visible par tous. Schéma Vitrine d'un magasin
Back-end
(Arrière-boutique)		 Ce moteur invisible installé sur un ordinateur distant traite vos données, vérifie vos droits et organise les calculs secrets. Le système vérifie votre mot de passe dans sa réserve sécurisée avant de vous laisser entrer. Schéma Coulisses d'un théâtre
Full-stack
(Complet)		 Ce terme désigne une application ou une personne qui maîtrise à la fois l'écran visible et les mécanismes secrets cachés. Votre application gère à la fois le formulaire affiché à l'écran et l'enregistrement secret en cuisine. Schéma Iceberg (haut et bas)
Composant Vous assemblez un bloc réutilisable d'interface que vous pouvez afficher sur plusieurs pages sans le reconstruire à chaque fois. Vous fabriquez un bouton d'achat identique sur toutes les fiches d'articles sans le redessiner. Dessin Briques de construction
Responsive
(Adapté à l'écran)		 Votre page réorganise automatiquement ses textes et ses images pour rester agréable sur un téléphone comme sur un grand moniteur. Les trois colonnes de l'ordinateur se placent sagement l'une sous l'autre sur votre téléphone portable. Pictogrammes Téléphone / Tablette / Écran
Wireframe
(Maquette fil de fer)		 Ce schéma rapide sans couleurs montre la place réservée au menu, aux textes et aux photos sur l'écran. Vous tracez des rectangles au feutre pour placer le logo, le menu et le texte d'accueil. Croquis Schéma en traits noirs
API
(Passerelle logicielle)		 Ce canal de communication permet à votre application de demander et recevoir des informations auprès d'un autre programme. Votre site demande la météo du jour à un service externe pour l'afficher sur votre page. Illustration Serveur avec plateau repas
Endpoint
(Point d'accès)		 Cette adresse web précise indique au serveur quelle action lancer ou quel type de renseignement vous voulez récupérer. L'adresse /api/produits renvoie la liste complète des articles disponibles dans votre magasin. Schéma Portes avec étiquettes
Code d'état HTTP
(Code de résultat)		 Ce nombre à trois chiffres indique immédiatement si le serveur a réussi votre demande ou s'il rencontre une panne. Le chiffre 200 annonce que tout va bien, alors que 404 signale que la page est introuvable. Feux tricolores Vert 200 / Rouge 500
JSON
(Format d'échange)		 Ce texte organisé avec des étiquettes et des valeurs permet à deux ordinateurs d'échanger des fiches sans se tromper. Vous écrivez {"prenom": "Sara", "age": 30} pour transmettre la fiche d'une participante. Fiche Tableau avec nom et valeur
Accessibilité
(Pour tous)		 Vous créez votre application pour qu'une personne en situation de handicap puisse naviguer, écouter et cliquer sans difficulté. Vous écrivez des textes lisibles pour les personnes malvoyantes qui utilisent une voix de synthèse. Symbole Silhouette blanche cercle bleu

4. Données et sécurité

Terme Explication en français facile (10 à 25 mots) Exemple simple Support visuel
Base de données Cette armoire électronique classe, conserve et retrouve toutes les informations de votre application dès que vous en avez besoin. Le carnet enregistre la liste de vos membres avec leurs adresses e-mail et leurs cotisations. Icône Cylindre à tiroirs
Modèle de données
(Schéma de base)		 Ce plan de construction liste les différentes catégories d'informations retenues et décrit les liaisons obligatoires entre ces éléments. Vous reliez la fiche d'un client à la liste de ses trois commandes passées. Schéma Rectangles reliés par flèches
SQL
(Langage de requêtes)		 Vous rédigez ces phrases précises pour demander à votre armoire de ranger, trouver, mettre à jour ou détruire des informations. Vous écrivez une phrase d'ordre pour réclamer uniquement les clients habitant dans votre commune. Dessin Loupe sur tableau de lignes
ORM Cet outil écrit les demandes complexes de stockage à votre place à partir de simples commandes habituelles de code. Vous tapez utilisateur.sauvegarder() et l'outil écrit la commande technique à votre place. Illustration Pont de traduction
Authentification Le système contrôle votre identité avec certitude en comparant votre identifiant personnel et votre mot de passe secret. Vous entrez votre adresse e-mail et votre code pour accéder à votre espace personnel. Icône Cadenas avec une clé
Rôle et permissions Ces règles précisent ce que chaque personne enregistrée a le droit de lire, ajouter, modifier ou supprimer dans l'application. Un membre peut lire les annonces, mais seul le responsable du club peut supprimer un compte. Badge Niveaux d'accès colorés
Jeton
(Token de session)		 Ce badge chiffré temporaire prouve que vous êtes bien identifié pour naviguer sur le site sans retaper votre mot de passe. Le navigateur garde ce pass secret pendant votre visite pour vous reconnaître d'une page à l'autre. Illustration Bracelet d'entrée de festival
Variable d'environnement
(Fichier .env)		 Vous rangez vos réglages confidentiels dans ce fichier isolé sans jamais publier ces clés secrètes avec le reste du code. Vous y stockez le mot de passe de votre base pour qu'aucun visiteur ne puisse le lire. Icône Coffre-fort étiqueté secret
Clé API Ce mot de passe exclusif autorise votre application à utiliser les services payants ou protégés d'un autre site partenaire. Votre site utilise cette clé secrète pour envoyer des e-mails avec un service postal en ligne. Icône Clé d'accès dorée
Hachage Cette méthode mathématique transforme un mot de passe en charabia définitif pour qu'aucun voleur ne puisse le deviner. Le mot secret devient une longue suite de lettres mélangées qu'aucun pirate ne peut recalculer. Schéma Hachoir à viande (sens unique)
Double authentification
(2FA)		 Vous fournissez deux preuves d'identité successives, comme votre mot de passe habituel puis un code envoyé sur votre smartphone. Vous tapez votre mot de passe, puis vous recopiez un code à six chiffres reçu par SMS. Illustration Porte avec deux serrures
HTTPS Ce cadenas numérique chiffre toutes les informations échangées entre votre écran et le serveur pour empêcher toute interception indiscrète. Le petit cadenas vert dans votre navigateur confirme que votre carte bancaire voyage à l'abri. Icône Cadenas dans l'adresse web
Injection de code
(Attaque pirate)		 Une personne malintentionnée tente de glisser des ordres pirates dans un formulaire pour tromper et piller votre système informatique. Un internaute saisit des caractères bizarres dans le champ recherche pour afficher des données confidentielles. Illustration Passoire bloquant les pierres

5. Tests et erreurs

Terme Explication en français facile (10 à 25 mots) Exemple simple Support visuel
Bogue
(Bug / Panne)		 Cette erreur dans l'écriture du code entraîne un mauvais affichage, un calcul faux ou le blocage complet de votre page. Le clic sur le bouton d'inscription ne déclenche rien du tout sur la page. Icône Petit insecte ou voyant rouge
Débogage
(Recherche de panne)		 Vous examinez méthodiquement votre programme pour repérer la cause exacte d'un dysfonctionnement et réparer la ligne fautive. Vous relisez les indications de l'ordinateur pour comprendre pourquoi une image refuse d'apparaître. Illustration Détective avec loupe
Test unitaire Vous lancez un contrôle automatique sur une fonction minuscule de votre code pour vérifier qu'elle renvoie le résultat parfait. Le programme teste que l'addition du panier donne bien dix euros pour deux articles à cinq euros. Dessin Éprouvette de laboratoire
Test d'intégration Vous vérifiez que deux morceaux distincts de votre application communiquent ensemble sans bloquer ni perdre la moindre information. Vous vérifiez que le clic sur le panier enregistre bien la commande dans la base. Schéma Deux engrenages emboîtés
Journal
(Logs)		 Ce registre automatique note toutes les actions, les visites et les pannes survenues sur la machine avec l'heure exacte. Le journal note l'heure exacte où le serveur s'est éteint et pourquoi il a planté. Document Carnet avec dates et heures
Recette
(Contrôle final)		 Vous testez l'ensemble des boutons et des écrans selon une liste précise avant d'ouvrir officiellement votre site au public. Vous cliquez sur chaque bouton du site pour confirmer que rien n'est resté en panne. Checklist Planche à pince cochée

6. Git et publication sur Internet

Terme Explication en français facile (10 à 25 mots) Exemple simple Support visuel
Git Cet outil enregistre chaque étape de votre code pour vous permettre de remonter dans le temps en cas d'accident. Vous pouvez annuler une bêtise commise hier et retrouver votre site intact en un clic. Schéma Frise avec arrêts de train
Dépôt
(Repository / Repo)		 Ce dossier spécial rassemble tous les fichiers de votre application et garde en mémoire l'historique complet de leurs changements. Votre projet d'application vit dans un dossier surveillé et sauvegardé sur GitHub ou GitLab. Icône Classeur d'archives sécurisé
Commit
(Étape validée)		 Vous enregistrez une étape propre de votre travail en ajoutant une note explicative courte pour marquer votre avancée. Vous validez votre travail avec la note : « Ajout de la page des tarifs ». Icône Tampon dateur sur feuille
Branche
(Piste de travail)		 Vous créez une voie séparée pour essayer une idée nouvelle sans risquer de casser la version officielle de votre site. Vous essayez un nouveau menu sans casser le site principal déjà visible par vos collègues. Schéma Aiguillage de voie ferrée
Push / Pull
(Envoyer / Rapatrier)		 Vous transférez votre travail vers le serveur distant ou vous rapatriez sur votre machine les nouveautés créées par votre équipe. Vous téléversez votre travail du soir sur Internet pour ne rien perdre si votre ordinateur s'éteint. Flèches Vers le haut et le bas
Fichier .gitignore Cette liste indique à Git les fichiers confidentiels ou temporaires qu'il ne doit jamais publier ni sauvegarder sur Internet. Vous y notez le fichier de vos mots de passe pour éviter de l'exposer au monde entier. Symbole Panneau d'interdiction d'accès
Déploiement
(Mise en ligne)		 Vous installez votre application sur un serveur connecté pour que n'importe qui puisse l'utiliser depuis son propre navigateur web. Vous lancez la mise en ligne pour que vos amis puissent enfin visiter votre boutique web. Illustration Fusée qui décolle
Nom de domaine et DNS Cet annuaire universel convertit un nom de site facile à retenir en adresse chiffrée comprise par les machines du réseau. Il transforme l'adresse facile monsite.fr en un numéro technique pour diriger le visiteur au bon endroit. Schéma Annuaire téléphonique
VPS
(Serveur virtuel dédié)		 Vous louez un compartiment privé sur un ordinateur distant qui reste allumé jour et nuit pour faire tourner votre site. Votre site fonctionne en permanence dans un appartement privé au sein d'un grand immeuble numérique. Dessin Immeuble avec appartements
Machine virtuelle
(VM)		 Vous faites tourner un second ordinateur fictif à l'intérieur de votre écran pour manipuler des programmes sans abîmer votre matériel. Vous démarrez un système Linux dans une fenêtre de votre Mac pour vous entraîner en sécurité. Capture Écran dans un autre écran
Conteneur
(Docker)		 Cette boîte logicielle autonome emporte votre application avec tous ses réglages pour s'exécuter à l'identique sur n'importe quel ordinateur. Votre collègue démarre votre site en une seconde sans devoir réinstaller tous les logiciels un par un. Illustration Conteneur de cargo fermé
Retour arrière
(Rollback)		 Vous réactivez en urgence la version précédente de votre site pour effacer immédiatement les conséquences d'une mise en ligne ratée. Votre nouvelle mise à jour plante les paiements ; vous revenez à la version d'hier en dix secondes. Bouton Bouton de marche arrière rouge
Stockage objet
(S3 / Bucket)		 Ce placard numérique conserve des millions de fichiers volumineux (photos, audios, vidéos, sauvegardes) sans limite de taille et à moindre coût. Votre application stocke les photos de profil des utilisateurs dans un bucket S3 au lieu de saturer le disque du serveur. Dessin Casier géant d'objets numérotés
Trafic sortant
(Egress)		 Ce volume de données quitte le centre de données dès qu'un internaute télécharge une image, écoute un audio ou ouvre un document. Quand mille personnes écoutent votre podcast en ligne, le transfert sortant génère du trafic réseau parfois surtaxé chez certains hébergeurs. Flèche Données sortant du datacenter
Jamstack / Pages Cette méthode compile tout votre site en pages légères prêtes à l'emploi et les distribue partout sur Terre pour un affichage instantané. Votre site Astro ou Vite est mis en ligne gratuitement sur Cloudflare Pages et s'affiche en quelques centièmes de seconde. Schéma Réseau mondial de serveurs relais
PUE
(Efficacité énergétique)		 Cet indice mesure le gaspillage d'électricité du bâtiment hébergeant les serveurs ; plus le chiffre est proche de 1, plus c'est écologique. Un centre de données avec un PUE de 1,10 consomme presque toute son électricité pour le calcul et ne gaspille rien en climatisation. Jauge Compteur vert d'énergie propre

7. Outils et logiciels de travail

Terme Explication en français facile (10 à 25 mots) Exemple simple Support visuel
IDE
(Atelier d'écriture)		 Ce logiciel rassemble sur un même écran votre traitement de texte de code, votre explorateur de dossiers et vos outils. Vous ouvrez votre projet dans cet atelier pour rédiger vos pages avec l'aide de l'ordinateur. Illustration Établi d'artisan outillé
VS Code Cet atelier gratuit très populaire accueille des extensions pour colorer votre texte, corriger vos fautes et faciliter vos saisies. Vous installez une extension pour colorer votre code et le rendre plus agréable à lire. Logo Ruban bleu officiel
Cursor Cet atelier d'écriture intègre une intelligence artificielle pour analyser vos fichiers et rédiger des modifications à partir de vos ordres. Vous demandez dans le panneau latéral : « Crée un formulaire de contact », et le code s'écrit tout seul. Capture Code + fenêtre d'échange IA
GitHub et GitLab Ces plateformes hébergent vos dépôts de code sur Internet pour protéger vos sauvegardes et simplifier le partage avec d'autres personnes. Vous partagez l'adresse de votre dépôt avec votre formateur pour qu'il regarde votre avancée. Logos Chat-pieuvre et renard
Cloudflare
(Pages et Workers)		 Ce service mondial héberge et protège votre site web pour l'afficher instantanément chez vos visiteurs tout en repoussant les attaques. Votre site se charge en une fraction de seconde pour un internaute situé à Paris ou à Montréal. Schéma Nuage orange et relais mondiaux
Docker Compose Cet outil allume tous les morceaux de votre application en une seule fois grâce à une recette de démarrage unique. Vous tapez une commande et vos trois logiciels de travail s'allument ensemble sans dispute. Schéma Chef d'orchestre guidant 3 blocs
Android Studio et Xcode Ces grands logiciels de fabricants permettent de construire, simuler et contrôler une application sur un téléphone virtuel Android ou iPhone. Vous lancez un faux téléphone sur votre écran d'ordinateur pour vérifier l'allure de votre bouton. Capture Faux smartphone sur l'écran
Terminal
(Ligne de commande)		 Cette fenêtre textuelle vous permet de donner des ordres directs à votre machine en tapant de courtes phrases au clavier. Vous tapez npm run dev pour allumer votre site en mode brouillon sur votre poste. Capture Fenêtre noire à texte blanc
Mermaid Cet outil transforme automatiquement des phrases ordinaires bien ordonnées en jolis schémas et graphiques d'architecture sans logiciel de dessin. Vous écrivez trois lignes de texte pour générer le dessin des étapes d'inscription d'un membre. Exemple Texte à gauche, schéma à droite

A. Mots à éviter dans les supports de cours

Dans les cours pour débutants, ces mots techniques ou anglophones compliquent inutilement la compréhension. Privilégiez systématiquement l'expression simple proposée ci-dessous :

Feature➔Fonctionnalité / Option
Stack technique➔Choix des technologies / Outils de fabrication
Front-end➔Partie visible / Écran utilisateur
Back-end➔Arrière-boutique / Moteur secret
Endpoint➔Adresse d'action / Point d'accès
Refactoring➔Nettoyage et simplification du code
Token➔Jeton de session / Badge d'accès
Commit➔Étape enregistrée / Validation datée
Branch➔Branche de brouillon / Piste de travail séparée
Deploy➔Mise en ligne sur Internet
Framework➔Boîte à outils prête à l'emploi
Build➔Fabrication / Assemblage du site
Rollback➔Retour en arrière d'urgence
Wireframe➔Croquis de l'écran / Plan en traits
User story➔Fiche de besoin / Histoire utilisateur
Bug / Debugger➔Panne, défaut / Trouver la panne et réparer
Log➔Journal des événements / Registre de bord
CLI / Terminal➔Fenêtre de commandes au clavier
Hardcoder➔Écrire en dur (sans réglage possible)
CI/CD Pipeline➔Chaîne automatique de fabrication

B. Mots incontournables qui peuvent rester

Ces noms de technologies et d'outils apparaissent sur les écrans réels et les boutons. Conservez leur nom d'origine, en l'accompagnant systématiquement d'une phrase explicative très simple :

Git
Cet outil enregistre l'historique complet de votre travail pour remonter dans le temps en cas d'erreur.
GitHub / GitLab
Ces plateformes en ligne sauvegardent vos dossiers de code et permettent de travailler ensemble sans danger.
VS Code
Ce logiciel gratuit sert d'atelier d'écriture pour rédiger, organiser et colorer vos lignes de code.
Cursor
Cet atelier d'écriture intègre une intelligence artificielle pour modifier vos fichiers selon vos demandes.
Docker
Cette boîte étanche fait tourner votre application à l'identique sur n'importe quel ordinateur sans rien dérégler.
Docker Compose
Cet outil démarre simultanément tous les morceaux de votre application avec une seule commande.
Cloudflare
Ce service en ligne met votre site sur Internet, accélère son affichage et repousse les pirates.
Android Studio
Ce logiciel officiel permet de tester votre application sur un téléphone Android virtuel.
Xcode
Ce logiciel d'Apple permet de tester votre application sur un iPhone virtuel sur ordinateur Mac.
HTML
Ce langage de base structure le squelette d'une page : titres, paragraphes, images et liens.
CSS
Ce langage visuel habille votre page avec des couleurs, des tailles de texte et des espacements.
JavaScript
Ce langage donne vie à votre page web en réagissant aux clics et aux saisies des visiteurs.
React / Next.js
Cette boîte à outils moderne permet d'assembler des pages web rapidement grâce à des blocs réutilisables.
SQL
Ce langage universel permet de poser des questions et d'ordonner des fiches dans une base de données.
HTTPS
Ce cadenas numérique protège la confidentialité des échanges entre le visiteur et votre site web.
JSON
Ce format de texte ordonné permet à deux ordinateurs de s'échanger des fiches de données sans erreur.
