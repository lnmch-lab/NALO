# Fiche cours - VIBE-CODING

Source : https://formations.mehdiguiraud.com/cours/SCAP/VIBE-CODING/fiche.html

Fiche cours — VIBE-CODING
Durée : 45 heures (15 séances de 3 heures)
Modalité : Hybride / Distanciel / Présentiel
Niveau : Débutant à intermédiaire
Description
Concevoir et livrer un MVP d'application web et/ou mobile en s'appuyant sur des assistants IA, des prompts structurés et les bonnes pratiques (cadrage, architecture, UX, données, API, auth, tests, sécurité, déploiement Cloudflare, Linux/conteneurs, documentation).
Objectifs
Cadrer un projet MVP (personas, backlog, risques).
Choisir une architecture simple et maintenable.
Implémenter interface, données, API et authentification.
Couvrir tests, sécurité et confidentialité de façon proportionnée.
Déployer (Cloudflare) et simuler un VPS Linux.
Documenter et présenter le projet devant un jury.
Programme (aperçu)
Séances 1–4
Cadrage, architecture, UX, socle Git/qualité.
Séances 5–9
Données, API, auth, front-end, mobile.
Séances 10–13
Tests, sécurité, Cloudflare, Linux/Docker.
Séances 14–15
Documentation, démo, revue finale.
Annexes outils & Lexique
GitHub/GitLab, Cloudflare, Android Studio, Xcode, VM Linux, Hébergement Cloud (S3, VPS, Pages).
Un lexique en français facile à lire et à comprendre (FALC) est à disposition pour lever les doutes sur le vocabulaire technique.
