🗂️ Espaces de travail & usage des agents

Organiser les sessions, inspecter les exécutions, comprendre l'usage ou la disponibilité.

Delta (Zed) ↗Desktop

Lancer des fils d'agents et relire leurs changements dans un espace de travail multijoueur.

Duckweed ↗Desktop

Exécuter agents de code, shells, diffs Git et sessions dans un espace de travail local multiplateforme.

llm.log ↗

Inspecter les coûts, tokens et traces de requêtes des modèles via un proxy local.

Parallel Code ↗Desktop

Exécuter des agents de code dans des worktrees Git isolés et relire leurs changements.

Shep ↗CLI

Orchestrer des agents de code en parallèle, jusqu'au commit, au push et aux brouillons de PR.

Superagent ↗Desktop

Utiliser Claude Code ou Codex dans un espace de travail macOS avec outils navigateur et iOS.

usage ↗Desktop

Voir les quotas des agents de code depuis la barre de menu macOS ou la zone de notification Windows.

Warp Terminal ↗

Un terminal orienté agents pour inspecter les workflows de code.
